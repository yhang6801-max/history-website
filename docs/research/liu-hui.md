# Liu Hui / 刘徽

生卒年仅记三世纪，未使用纪念活动推定生年。263 年注书依据古籍提要与学术研究；《九章算术》原书、刘徽注、后世《海岛算经》题名严格区分。割圆、开方与体积研究依据中科院资料，未将祖冲之父子的后续成果全部归给刘徽。此前 MacTutor 刘徽页面返回的正文实际讲丢番图，判为内容错配，未作为来源。四节三事件中英对应。
