# Robert Boyle / 罗伯特·波义耳

核对 1627–1691、牛津 1650 年代、1660 实验书/皇家学会、1661 怀疑派化学家、1662 定量关系、1668 伦敦。保留胡克的气泵/实验合作贡献、财富和宗教背景。波义耳定律注明气体量与温度不变及理想近似；微粒论、元素概念不直接等同于现代原子/周期表。来源对迁牛津年份有 1655/1656 表述差异，因此使用准确的年代范围。
