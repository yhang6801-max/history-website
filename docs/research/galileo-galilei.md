# Galileo Galilei / 伽利略·伽利莱

核对 1564–1642、1589 比萨、1592 帕多瓦、1609 改进望远镜、1610 书与任职、1616 警告、1632 对话、1633 审判、1638 两门新科学。未称望远镜由其首次发明；四颗木星卫星与金星相位不等于单独证明所有日心说细节。父母与任职关系对应，未使用比萨塔落球或临审抗辩等未确证故事。五节十事件双语对应。
