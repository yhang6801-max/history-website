# Nicolaus Copernicus / 尼古拉·哥白尼

核对 1473、1491、1496、1503、1516–1519、1536、1543；区分舅父、教士职位和教会法学位，不误写为天文学博士。没有将椭圆轨道、万有引力或完整现代太阳系理论归于哥白尼。没有将发表推迟唯一归因于恐惧教会，也未引用未经独立核验的名言。五节七事件双语对应，原始来源署名保留。
