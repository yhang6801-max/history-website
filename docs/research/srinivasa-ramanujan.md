# Srinivasa Ramanujan / 斯里尼瓦瑟·拉马努金

复用已查证来源。核对 1887–1920、1912 港务局、1913 通信、1914 剑桥、1916 研究学位、1918 两项院士资格、1919 返印。未将当时研究学位称为 PhD。分拆公式明确与哈代合作，笔记不等于全是已证明定理；病因保留争议。模拟西塔函数区分本人例子与后世理论。五节八事件中英对应。
