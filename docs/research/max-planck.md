# Max Planck / 马克斯·普朗克

核对生卒日、1879 年博士、1885 年基尔职位、1900 年辐射定律/量子推导、1918 年奖项年度、1930–1937 年学会会长。奖项年度不与后来的领受或演讲日期混写。保留普朗克最初的经典物理取向；不把光子或成熟量子力学归为他独立完成。纳粹时期支持部分同事但未能阻止机构被控制，依据学会自身历史说明；1945 年儿子埃尔温被处决不改写为自然死亡。Nobel 网站 403 未重试，未作为已读取证据。
