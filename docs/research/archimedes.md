# Archimedes / 阿基米德

复用已读取的 MacTutor、DSB 和重写本学术说明。287 BCE 是来源中的通行估计而非自行推算，明确不确定；212 BCE 为攻城去世年份。未采用洗澡喊声、镜面焚船或精确作品年表等难核实传说。力学提示与几何证明、古代方法与后世微积分分开表述。四节三事件逐项对应。
