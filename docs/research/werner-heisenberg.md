# Werner Heisenberg / 维尔纳·海森堡

核对矩阵力学中海森堡、玻恩、约尔当的不同贡献；1927 年不确定性及莱比锡职位、1932 年奖项年度。任研究所负责人采用本机构年表和档案馆的 1942 年；MacTutor 的 1941 年说法未采用。战时计划未造出炸弹不等于证明故意破坏，未猜测 1941 年与玻尔会面的意图。原理表述使用同一状态中位置/动量分布的限制，避免仅归因于仪器扰动。
