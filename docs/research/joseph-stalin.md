# Joseph Stalin / 约瑟夫·斯大林

生年用LOC规范记录的1878，时间线注明后来官方1879差异，不混用儒略历/公历日。逐段核对1922、1928、1932—1933、1936—1938、1939、1941、1943、1945、1953。工业能力与实际产出、指标、外部技术、劳动者贡献分开；强制集体化、饥荒、劳改与清洗不是功绩；抗战贡献区分斯大林、军民、指挥官与盟国。国务院两篇正文已读取，LOC规范记录与档案展/国家研究相关内容搜索可读，展览正文未能打开，未重试。不开列争议伤亡数字，不编造引语。图片PD-USGov依据来自具体Commons文件及FDR公共档案来源链；Flickr权利人原页访问被拒绝，不能声称独立重读该页。
