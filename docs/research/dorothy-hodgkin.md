# Dorothy Hodgkin / 多萝西·霍奇金

核对 1910–1994、1928 萨默维尔、1934 回牛津/胰岛素起点、1945 青霉素、1955 B12、1964 化学奖、1969 胰岛素。获奖早于胰岛素三维结构完成，不能倒置。结构测定与抗菌发现/临床开发分开；B12、青霉素不误称蛋白质。团队贡献明确而不将所有分子研究归为单人独立完成。
