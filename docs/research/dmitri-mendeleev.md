# Dmitri Mendeleev / 德米特里·门捷列夫

核对 1834–1907、1860 卡尔斯鲁厄、1867 教授、1869 周期体系、1871 修订、1875–1886 镓/钪/锗的验证。明示迈耶等先驱，原子量与原子序数分别处理，1913 莫塞莱研究在其去世后。未写梦中一次完成周期表的轶事，未将不准确预言一并称为成功。
