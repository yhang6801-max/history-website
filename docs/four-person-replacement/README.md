采用的是特定授权/政府作品依据，不是“人物去世即自由使用”。当前CC许可允许结合媒介合理署名，4.0条款还明确可链接到包含必需信息的资源。本网站每张卡片直接链接其唯一详情，首屏有完整署名区入口，所有署名同等显著。现有逐图原始记录未发现要求首页直接印署名的额外条款，故无需为这一布局替换其余图片。机构指定的署名行、许可版本、来源、修改及不暗示背书说明均保留。

这一判断限定于当前传记配图展示、裁切和压缩，不涵盖脱离详情页的素材再分发，也不保证全球所有用途无风险。德语3.0法律全文工具访问失败，公开deed和机构署名说明可访问，记录没有写成阅读全文。NARA目录、Flickr原页部分访问被工具拒绝，未绕过；使用其已有公开合作导入与许可复核记录，而非声称新获得私人授权。
